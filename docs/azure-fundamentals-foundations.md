# EZROME Foundations: Azure Fundamentals

This learning module is educational content, not Microsoft certification training or a promise of any particular Azure architecture. It uses the broad subject areas described in Microsoft’s Azure Fundamentals learning paths: cloud concepts; Azure architecture and services; and Azure management and governance.

| Learning area | Foundations focus | EZROME connection |
| --- | --- | --- |
| Cloud concepts | Service models, deployment models, shared responsibility, scalability, elasticity, availability, and consumption thinking. | Compare IaaS, PaaS, and SaaS while tracing what EZROME owns versus what a provider manages. |
| Azure architecture and services | Regions, region pairs, availability zones, resource groups, subscriptions, management groups, compute, networking, storage, databases, identity, monitoring, and integration. | Map the web client, API, database, managed media storage, authentication, analytics, and offline client into cloud service families. |
| Azure management and governance | Role-based access control, policies, tags, locks, cost management, service limits, monitoring, and lifecycle decisions. | Apply least privilege, environment labels, founder-controlled access, release checklists, media-retention decisions, and cost awareness. |
| Security and responsibility | Identity, secrets, encryption, network controls, secure development, data protection, and the customer/provider responsibility boundary. | Keep secrets and signing material server-side, protect creator rights, support deletion and moderation, and verify every release boundary. |
