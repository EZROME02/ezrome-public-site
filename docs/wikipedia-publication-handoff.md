# EZROME Wikipedia publication handoff

## Current assessment

EZROME should not be automatically published as a Wikipedia article merely because the repository is now public. English Wikipedia generally requires an organization or product to have significant coverage in reliable, independent secondary sources; a company is not automatically notable because it exists, has a public website, or has a public GitHub repository. The relevant guidance also notes that only a small percentage of organizations meet the requirements for a standalone article.[^1]

Because this project is controlled by its founder, preparing or editing an article about EZROME would create a conflict of interest. Wikipedia strongly discourages direct conflict-of-interest editing and recommends disclosure and proposal through the Articles for creation process instead.[^2] The safest path is therefore to prepare a neutral, source-led draft for human review and submit it through Wikipedia's draft workflow only if sufficient independent coverage exists.[^3]

## Evidence required before submission

The draft should rely primarily on independent reporting, interviews, books, or other reliable secondary sources that discuss EZROME substantially. The project's own website, GitHub repository, press release, social profiles, and founder-authored materials can verify basic facts but do not independently establish notability. Do not submit a promotional product page, claims about future success, unlaunched features, or unsourced statements about cultural impact.

| Evidence | Suitable use | Current status |
|---|---|---|
| Independent substantial coverage | Establishes notability and supports article claims | Must be collected by the owner |
| Public EZROME website | Verifies official product description and links | Available, but not sufficient alone |
| Public GitHub repository | Verifies implementation history and open-source/public code claims | Available, but not sufficient alone |
| Play Console listing or release record | Verifies a release only after publication | Owner-controlled and not yet a substitute for independent coverage |
| Founder or company social posts | May support dates or announcements | Not independent; use sparingly |

## Human-controlled submission route

If the independent-source requirement is met, the owner should disclose the relationship to EZROME on the draft's talk page and use Wikipedia's Articles for creation process. The draft should be written in a neutral encyclopedic style, contain inline citations for every material claim, avoid marketing language, and be submitted for review rather than moved directly into the encyclopedia's mainspace.[^2] [^3]

An automated bot should not create, promote, or repeatedly resubmit the article. Wikipedia's guidance specifically warns that drafts generated entirely by large language models will be rejected, so any draft prepared with assistance must be substantially checked, rewritten, sourced, and approved by a human editor before submission.[^3]

## Suggested neutral draft outline

1. **Lead:** Identify EZROME only as the subject supported by sources; do not describe it as successful, leading, or more than the sources establish.
2. **Development:** Summarize publicly documented development milestones with citations.
3. **Features:** Describe only released and independently reported features, not roadmap items.
4. **Reception or coverage:** Include independent commentary, reviews, interviews, or reporting if available.
5. **References:** Cite the independent sources directly and consistently.
6. **External links:** Include only the official website and public repository if appropriate under Wikipedia's external-link guidance.
